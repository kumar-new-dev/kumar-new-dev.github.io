About

I'm a full-stack developer. My main project is myexpenses, a personal income and expense tracker that I migrated from a local Python/SQLite app to the cloud — Cloudflare Pages for hosting, Convex for the database and backend, and Better Auth for sign-in — running on free tiers.

I work across the whole stack: plain JavaScript and TypeScript on the front end, Python for the original backend and migrations, and serverless backends with automated deployments through GitHub Actions.

My newest project is Black Friday Deal Swipe, a swipe-to-save deal app for Black Friday 2026 — 75 real deals, a taste-scored deck, and a secured Convex backend with rate limiting and scheduled expiry pruning, deployed on the same stack.
